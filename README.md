# 小數奇幻冒險島 - 國小四年級數學 (math4-09)

專為國小四年級數學「小數」單元設計的互動闖關學習網站。

## 功能特色

1. **青蛙跳數線**：動態拖曳青蛙探索十分位、百分位數線及小數點定位。
2. **猜拳天平PK賽**：結合猜拳與天平傾斜物理效果的小數比大小對決。
3. **生活情境直式計算**：生活化購物與長度情境，引導小數點直式對齊與進位。
4. **小數排序卡牌**：由小至大卡牌拖曳排序互動挑戰。
5. **小數島嶼大冒險（10題闖關）**：互動式測驗題庫，即時評分與星星結算。
6. **懸浮草稿計算紙**：隨點隨開的草稿板，方便學生隨時演算。
